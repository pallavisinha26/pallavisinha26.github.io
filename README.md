## View the portfolio

The portfolio is a static HTML website and can be published using
**GitHub Pages**.

Once published, the site will be available at:

`https://<your-github-username>.github.io/`

Replace `<your-github-username>` with your GitHub username.

## Repository setup

For a straightforward GitHub Pages setup, keep the published HTML file
and its image asset in the repository's root directory.

Suggested structure:

``` text
.
├── index.html
├── pallavi.jpg
└── README.md
```

Before publishing:

1.  Rename the portfolio HTML file to `index.html`.
2.  Add the portrait image as `pallavi.jpg` in the same folder, or
    update the image path in `index.html` to match your chosen filename
    and location.
3.  Review the email address, LinkedIn URL, employment dates, project
    details, certifications, and experience figures.
4.  Commit and push the files to your GitHub repository.

## Publish with GitHub Pages

1.  Create a GitHub repository. For a user site, name it
    `<your-github-username>.github.io`.
2.  Upload `index.html`, `pallavi.jpg`, and this `README.md` to the
    repository's root.
3.  Open the repository's **Settings → Pages**.
4.  Under **Build and deployment**, select **Deploy from a branch**.
5.  Select the `main` branch and the `/ (root)` folder, then save.
6.  Wait for GitHub Pages to complete deployment. The published URL will
    appear in the Pages settings.

For a project repository with a different name, the URL will usually be:

`https://<your-github-username>.github.io/<repository-name>/`

## Customisation

-   Update the content directly in `index.html`.
-   Replace `pallavi.jpg` with your preferred professional portrait,
    keeping the filename consistent.
-   Update the LinkedIn URL and email address if they change.
-   Keep project outcomes and metrics accurate and supportable.
-   Test the site on desktop and mobile after making changes.
